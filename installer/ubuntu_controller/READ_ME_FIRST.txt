BIDGUARD 법원경매 관제기 — 우분투 설치 안내
================================================

■ 설치 (한 번만)
  1. 이 압축 파일을 끝까지 풉니다. (파일 관리자에서 오른쪽 단추 → '여기에 풀기')
  2. 풀린 폴더의 install_court_auction_controller.sh 에서
     오른쪽 단추 → '프로그램으로 실행' (Run as a Program)
     - 터미널 창이 열리고 관리자 비밀번호(로그인 비밀번호)를 한 번 묻습니다.
       입력해도 글자가 보이지 않는 것이 정상입니다.
     - '프로그램으로 실행'이 메뉴에 없으면 그 폴더에서 터미널을 열고:
         bash install_court_auction_controller.sh
  3. 화면 질문에 [예]/[확인] 을 누르면 끝납니다.
     - 인터넷이 없어도 됩니다. 부품이 이 묶음 안에 들어 있습니다.
     - 컴퓨터를 켜면 관제기가 자동으로 켜지도록 등록합니다.
     - 이미 설치된 관제기가 있으면 자료(수집기 목록·작업·API 키·DB)를 지키고
       프로그램만 새 판으로 바꿉니다. 예전 글록 판 서비스도 정리합니다.
     - 실패하면 설치 전 상태로 자동으로 되돌립니다.
  4. 마지막 화면에 나오는 주소를 적어 둡니다.
       브라우저에서 관제기 열기 :  http://(이 컴퓨터 주소):8080
       수집기에 넣을 주소        :  (이 컴퓨터 주소):8080

■ 주의
  - 관리자 로그인은 지금 admin / admin 입니다. 관제기 프로그램이 켜질 때마다
    admin/admin 으로 되돌리게 되어 있어 설치 프로그램에서 바꿀 수 없습니다.
    집 안 네트워크 밖으로 관제기 주소를 열지 마십시오.

■ 지우기
  sudo bash /opt/bidguard/controller/uninstall_court_auction_controller.sh
  - 자료는 지우지 않고 /opt/bidguard/controller_data_날짜 로 옮겨 두는 것이 기본입니다.
  - 다시 설치하면 그 자료를 찾아 되살릴지 묻습니다.

■ 문제가 생기면
  - 설치 화면 마지막에 나오는 기록 파일(/tmp/bidguard_controller_install_...log)을
    관리자에게 보내 주십시오.
