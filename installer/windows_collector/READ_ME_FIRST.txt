BIDGUARD 법원경매 수집기 — 윈도우 설치 안내
================================================

■ 설치 (한 번만)
  1. 이 압축 파일을 끝까지 풉니다. (압축 파일 안에서 바로 실행하면 안 됩니다)
  2. 풀린 폴더의 Install_Court_Auction_Collector.bat 을 더블클릭합니다.
  3. 설치 창에서 [다음] → 점검 결과 확인 → 수집기 이름 넣기 → [설치]
     - 인터넷이 없어도 됩니다. 파이썬과 부품이 이 묶음 안에 모두 들어 있습니다.
     - 관리자 권한이 필요 없습니다.
     - 예전 수집기가 있으면 이름·설정·모은 자료를 그대로 옮깁니다.
     - 실패하면 설치 전 상태로 자동으로 되돌립니다.
  4. 끝나면 바탕화면의 'BIDGUARD Court Auction Collector' 로 수집기를 켭니다.

  "Windows의 PC 보호" 파란 창이 뜨면: [추가 정보] → [실행] 을 누르십시오.
  (인터넷에서 받은 파일이라 윈도우가 한 번 묻는 것입니다)

■ 수집기 이름
  - jiju 뒤에 숫자 네 자리(예: jiju0001) → 관제형: 관제기의 지시를 받아 수행
  - 그 밖의 이름 → 보급형: 직접 입력한 내용을 수집
  - 관제기 '수집기' 메뉴에 등록한 이름과 같아야 합니다.

■ 화면(브라우저) 권장
  - 해상도 1920×1080, 윈도우 배율 100%
  - 브라우저 창은 최대화, 브라우저 확대 100% (Ctrl 과 0)
  - 수집기는 화면을 보고 일합니다. 법원경매 페이지 전체가 브라우저 한 화면에
    들어와야 단추와 글자를 잘 알아봅니다.
  - 화면이 잘리면: ① 윈도우 설정 > 디스플레이 > 배율 100%
                   ② 그래도 잘리면 브라우저에서 Ctrl 과 - 로 90%·80% 로 줄여
                      한 화면에 들어오게 합니다.
  - 설치 프로그램 '점검' 화면에서 이 컴퓨터의 실제 크기와 판정을 보여 드립니다.

■ 피코2 펌웨어 업데이트
  - 수집기를 먼저 설치한 뒤, 시작 메뉴 BIDGUARD > 'BIDGUARD Pico2 Firmware Update'
    (또는 이 폴더의 Update_Pico2_Firmware.bat)
  - 수집기를 닫고, 피코2를 USB로 꽂고, [업데이트 시작] 한 번이면 됩니다.
  - 자동 전환이 안 되면 화면 안내대로 BOOTSEL(흰 단추)을 누른 채 USB를 다시 꽂습니다.
  - 피코1(RP2040) 보드나 망가진 펌웨어 파일은 넣지 않습니다.

■ 지우기
  - 시작 메뉴 BIDGUARD > 'BIDGUARD Court Auction Collector Uninstall'
    또는 윈도우 설정 > 앱 > 'BIDGUARD 법원경매 수집기'
  - 모은 자료는 지우지 않고 따로 옮겨 두는 것이 기본입니다.

■ 문제가 생기면
  - 설치 창 마지막 화면의 [설치 기록 열기] 내용을 관리자에게 보내 주십시오.
