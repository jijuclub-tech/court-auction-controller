## 검수 포인트
1. 감정평가서 다운로드 경로에 수집을 스스로 막는 코드가 없는지
2. reCAPTCHA / 보안문자 처리가 “시도 후 사용자 호출” 원칙을 지키는지 (자동 포기 금지)
3. 맵 기반 프로그램 우선 처리가 정상 동작하는지
4. 저장 경로·API 키·파일 전송이 관제기 중심으로 설계되었는지

## 테스트 요청
- `install.bat` 설치 후 `python main.py` 실행
- 감정평가서 다운로드 흐름이 중간에 스스로 중단되지 않는지 확인
- 로그에 불필요한 차단·억제 메시지가 없는지 확인

검수 결과는 이슈 댓글로만 남겨 주십시오.  
코드 변경은 하지 마십시오.
