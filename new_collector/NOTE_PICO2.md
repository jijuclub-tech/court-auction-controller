# 입력 방식 정책

기본은 **피코2 HID** 입니다.

## 접근 등급에 따른 Selenium / Playwright 사용

- **공공기관 사이트** (*.go.kr, courtauction.go.kr 등): **자동으로 사용하지 않음**. 피코2만.
- **그 외 사이트**: 수집기 작동 **전 항상** 사용자에게 선택 문의.
  - 주의 안내 표시: 사이트에 기록이 남을 수 있으며 로봇 차단이 될 수 있음.
  - 반복 선택되거나 이전 문제가 있으면 옵션을 제시하지 않음.
- 선택 결과는 로그·설정·맵에 기록하고 UI에 알림.

자세한 내용은 `map/courtauction_map.md` 및 `core/access_policy.py` 참조.

## 화면 배율

피코2는 절대 좌표로 클릭하므로 **디스플레이 배율과 브라우저 확대율을 100%**로 맞춰야 합니다.

- 수집기 시작 시 배율 확인 후 100%가 아니면 경고 표시
- Windows: 설정 → 디스플레이 → 배율 100%
- 브라우저: Ctrl+0 으로 확대율 100%


봇 탐지를 피하기 위해 `core/human_input.py`의 `HumanHID`를 사용합니다. (피코2 경로)

- 마우스 이동: 베지어 곡선 + 가속/감속
- 클릭: 미세 정지·지터
- 타이핑: 글자별 가변 딜레이 + 가끔 오타·백스페이스
- 전체 속도: ±50%~80% 랜덤 변동
