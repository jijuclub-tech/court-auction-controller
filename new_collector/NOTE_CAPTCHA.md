# 보안문자 / 열람하기 다이얼로그 처리 방침

사이트 맵 원칙: 1.사람 → 2.AI → 3.프로그램  
입력 수단: 피코2 (HID)  
여유 시간: 3~5초

## 1. 열람하기 다이얼로그 (reCAPTCHA)

맵 항목 1 기준.

- 프로그램이 체크 상태를 확인
- 이미 체크되어 있으면 "열람하기" 버튼 클릭 (피코2)
- 체크 필요 시: 경고음 → 3초 대기 → 체크 후 열람하기
- 실패 시: 사용자 호출

자동 우회는 하지 않습니다. 맵에 적힌 규칙만 따릅니다.

## 2. 등기부등본 보안문자

맵 항목 2 기준.

- 1차: AI가 문자를 인식한 뒤 피코2로 입력
- 실패 시: 사용자 호출
- 성공 사례가 쌓이면 프로그램 규칙으로 고정

AI 인식 자체는 외부 AI(관제기에서 제공) 또는 사람 확인으로 처리합니다.  
수집기 코드 안에 자동 우회 로직은 넣지 않습니다.

## 공통

- 모든 게이트 통과 시 3~5초 여유
- 실패하면 `needs_human: true`로 관제기에 보고
- 관제기가 사용자에게 알림 (bidguard 0단계)
