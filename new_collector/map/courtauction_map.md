# 대법원 경매 사이트 맵
# Site: courtauction.go.kr
# 처리 원칙: 1.사람 → 2.AI → 3.프로그램
# 통과 여유 시간: 3~5초

## 시작 시 옵션 메뉴 (항상 표시)

수집기 Start 클릭 시 아래 옵션 다이얼로그를 먼저 표시한다.

1. 웹페이지 수집 프로그램(Selenium/Playwright) 사용 여부 (공공기관은 자동 미사용)
2. 천천히 / 보통 / 서둘러 + 기본 50분 작업 후 5분 휴식 (로그아웃 후 재접속)
3. 작업 시간대: 주간 / 야간 / 주간+야간
4. 속도: 1~5 (3=보통) 또는 자동
5. 로그인 아이디/암호 저장 또는 사용자 호출
6. 추가 AI: ChatGPT, Gemini, Claude, Grok, Local AI 선택 (아이디/비번 Settings에서)
7. 기본 Gemini API (관제기에서 상위 버전 수신)
8. 기타 (추후 확장)

선택 결과는 settings.json 및 로그에 기록.


- **공공기관 사이트** (예: *.go.kr, courtauction.go.kr): Selenium / Playwright **자동 사용 안 함**. 피코2 HID만 사용.
- **그 외 사이트**: 수집기 작동 전 항상 사용자에게 선택 문의.
  - 옵션: Selenium/Playwright 사용 또는 피코2만 사용.
  - 주의 안내: "사이트에 접속 기록이 남을 수 있으며, 로봇 차단 조치가 취해질 수 있습니다."
  - 반복 선택 또는 이전 문제 발생 시: 옵션을 제시하지 않고 피코2만 사용.
- 선택 결과는 로그 및 맵에 기록·알림.

## 방해 장면 목록

### 1. 열람하기 다이얼로그 (reCAPTCHA 확인)
- **장면 설명**: 감정평가서 등 문서 열람 시 나타나는 모달. "로봇이 아닙니다." + reCAPTCHA 로고 + 파란 "열람하기" 버튼.
- **캡처 참조**: 사용자 제공 스크린샷 (2026-11-06)
- **해결 방법**:
  - 체크 상태 확인 (이미 체크된 경우 많음)
  - "열람하기" 버튼 클릭 (피코2 기본)
  - 체크 필요 시: 경고음 → 3초 대기 → 체크 후 열람하기
- **처리 우선순위**: 프로그램(규칙) > AI > 사람
- **여유 시간**: 3~5초
- **상태**: 초기 등록 (사람/AI 해결 사례 추가 필요)

### 2. 등기부등본 보안문자
- **장면 설명**: 등기부등본 열람 시 보안문자 입력 요구
- **해결 방법**:
  - 1차: AI가 문자 인식 후 입력 (피코2)
  - 실패 시: 사용자 호출
- **처리 우선순위**: AI → 사람 → (성공 시 프로그램 규칙화)
- **여유 시간**: 3~5초
- **상태**: 정책 확정, 사례 수집 필요

## 맵 운영 규칙
- 새로운 방해 장면 발견 시: 화면 캡처 → 해결 과정 기록 → 이 맵에 추가
- 사이트별로 별도 저장
- 동일 장면 반복 시 프로그램이 우선 처리하도록 규칙 강화
- 모든 게이트 통과 시 3~5초 여유 시간 적용
- 입력 방식 선택은 위 정책에 따라 항상 사전 확인 후 기록
