# 대법원 경매 사이트 맵
# Site: courtauction.go.kr
# 처리 원칙: 1.사람 → 2.AI → 3.프로그램
# 통과 여유 시간: 3~5초

## 방해 장면 목록

### 1. 열람하기 다이얼로그 (reCAPTCHA 확인)
- **장면 설명**: 감정평가서 등 문서 열람 시 나타나는 모달. "로봇이 아닙니다." + reCAPTCHA 로고 + 파란 "열람하기" 버튼.
- **캡처 참조**: 사용자 제공 스크린샷 (2026-11-06)
- **해결 방법**:
  - 체크 상태 확인 (이미 체크된 경우 많음)
  - "열람하기" 버튼 클릭 (피코2)
  - 체크 필요 시: 경고음 → 3초 대기 → 체크 후 열람하기
- **처리 우선순위**: 프로그램(규칙) > AI > 사람
- **여유 시간**: 3~5초
- **상태**: 초기 등록 (사람/AI 해결 사례 추가 필요)

### 2. 등기부등본 보안문자
- **장면 설명**: 등기부등본 열람 시 보안문자 입력 요구
- **해결 방법**:
  - 1차: AI가 문자 인식 후 입력 (피코2)
  - 실패 시: 사용자 호출
- **처리 우선순위**: AI → 사람 → (성공 시 프로그램 규칙화)
- **여유 시간**: 3~5초
- **상태**: 정책 확정, 사례 수집 필요

## 맵 운영 규칙
- 새로운 방해 장면 발견 시: 화면 캡처 → 해결 과정 기록 → 이 맵에 추가
- 사이트별로 별도 저장
- 동일 장면 반복 시 프로그램이 우선 처리하도록 규칙 강화
- 모든 게이트 통과 시 3~5초 여유 시간 적용
