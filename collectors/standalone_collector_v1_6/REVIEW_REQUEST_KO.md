# 검수 요청 — 단독 수집기 v1 (클로드 검수용)

**검수만 해 주세요. 코드를 고치지 마세요.** 의견은 이 폴더 밖 새 파일(예: `REVIEW_RESULT_<이름>_<날짜>.md`)로 남기고, 이 폴더 파일은 바꾸지 말아 주세요. 바꾸면 SHA256SUMS 가 깨져요.
GitHub 올리기는 검수 뒤 지휘자 봇이 코드만 해요(DB·자료 제외).

## 범위
- 코드: `standalone/*.py` (page_guard.py·click_guard.py 는 기존 파일 사본, `core/` 는 피코2 링크 원본 사본)
- 단계표: `collector_kb/sites/*.json`
- 문서: README_KO.md, CHANGES_KO.md, SERVER_API_KO.md
- 시험: `python3 tests/run_all.py` (사이트 접속 없음)

## 꼭 봐 주실 것
1. **입력 규칙**: 피코2 말고 다른 입력 길(Playwright·CDP·JS·pyautogui·SendInput·법원 직접 HTTP)이 하나도 없는지. `hw.py` 의 BaseHW 만 입력을 내보내는지.
2. **입력 직전 확인**: 모든 클릭·키·글자 앞에 `Runner.input_check` 가 화면 오류를 확인하는지, 복구(로그아웃) 중 허용 입력이 로그아웃·뒤로·탭 닫기뿐인지.
3. **429**: 쉬는 시간 기록이 로그아웃보다 먼저 저장되는지, 로그아웃 성공 판정(로그인 보임+로그아웃 없음)이 충분한지, 같은 날 2번째 종료가 되는지, 다시 켜도 쉬는 시간이 지켜지는지.
4. **인증서·결제·발급**: DANGER_WORDS·ClickGuard 가 빠짐없이 막는지, 로그인 단계 완화(LOGIN_TAB_OK)가 위험하지 않은지.
5. **캡차**: 어떤 경우에도 자동 판독·자동 입력이 없는지(CHANGES 6번, 지시와 다르게 한 부분).
6. **비밀값**: 평문 파일 저장 없음, DPAPI 저장은 사람이 '예' 할 때만, 기록·화면 사진·예외 글·피코 기록에 값이 안 남는지, 설정 파일 비밀 칸 거부.
7. **DB 받기**: 경로 검사(safe_rel)로 폴더 밖 쓰기·코드 받기가 막히는지, SHA 불일치 때 안 바꾸는지, 서버 실패 때 로컬로 계속하는지, 시험 로그인 값이 어디에도 안 적혔는지.
8. **STOP**: 작업별 STOP·STOP_ALL·예전 STOP(법원만)이 맞는지, 프로그램이 STOP 을 스스로 지우지 않는지.
9. **저장**: NAS→D:→C: 순서, 옮길 때 SHA 확인 뒤에만 원본 삭제.
10. **법원 단계표**(`court_dongbu.json`): 예전 고정 좌표를 비율 상자로 옮긴 것이라 실제 화면과 맞는지 확인 필요(verified=false). 법원 선택·검색·다운로드 단계가 위험한 버튼을 누를 가능성.
11. 빠진 것: 여러 수집기 공통 429(한 대가 맞으면 다 같이 쉼)는 이 버전에 없음(각 노트북 자기 상태만) — 필요 여부. AI(제미나이)에 화면 사진을 보낼 때 개인정보가 섞일 수 있는 점(로그인 단계에서는 AI 안 씀).
